# Mini-Baymax Phase 1 Prototype

## Features

- Modular structure
- Facial and voice emotion detection are not implemented; the stubs return no prediction.
- Basic chatbot responses
- Emotion logging to JSON

This is an educational prototype, not a clinical or mental-health tool. The local
mood log can contain sensitive information; keep it on a trusted device and do not
commit `mood_log.json`.

## Usage

Run the main program:
python main.py
